# Siyu Photo Portfolio

一个使用原生 HTML、CSS 和 JavaScript 构建的响应式摄影作品集。

## 功能

- 11 张真实摄影作品
- 响应式瀑布流作品墙
- 街拍、自然、风光、日落分类筛选
- 点击图片打开灯箱预览
- WebP 图片压缩与响应式 `srcset`
- 适配手机、平板和桌面屏幕

## 本地运行

直接用浏览器打开 `index.html`。

## 图片说明

- `images/*-card.webp`：用于作品墙的轻量版本
- `images/*.webp`：用于灯箱的大图版本
- 原始照片没有被修改
- 上传版本已经移除 EXIF 信息
